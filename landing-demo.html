FAQ

Pertanyaan umum

Apakah benar-benar gratis untuk memulai?
Ya. Paket Pemula gratis selamanya untuk tim sampai 5 orang. Tidak diminta kartu kredit.
Bisakah data saya dipindah dari aplikasi lain?
Bisa. Kami sediakan import dari spreadsheet (CSV/Excel) dan panduan migrasi gratis untuk paket Tim ke atas.
Apakah ada aplikasi mobile?
Ada — tersedia untuk Android dan iOS, sudah termasuk di semua paket.
Bagaimana jika saya ingin berhenti?
Batal kapan saja dari halaman pengaturan, tanpa denda. Data bisa diekspor sebelum akun ditutup.
Apakah data saya aman?
Data dienkripsi saat transit (TLS) dan saat disimpan. Backup harian otomatis di lokasi berbeda.

Siap merapikan cara tim lo kerja?

Gabung 2.000+ tim yang sudah beralih. Gratis 14 hari, tanpa kartu kredit.
